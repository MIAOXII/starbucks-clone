🌷 About The Project

Welcome to my little coffee corner!

Starbucks Website Clone is my first-ever frontend development project, created using HTML5 and CSS3.

Inspired by the Starbucks website, this project was my first step into transforming creative ideas into beautiful webpages.

I explored layouts, typography, images, hover effects and responsive design while building this project.
